# Onam Flowers Admin (Cloudflare Pages)

Role-gated web console for the "Swiggy for Flowers" platform.

- **Owner (super-admin)** — live ops map, all orders, analytics, vendor/partner
  approvals, commission settlements, coupons. (Phase 6)
- **Vendor** — own store catalog, live stock, order queue, settlement reports.
  (Phase 5)

Built in Phase 5–6 as a Vite + React app with Leaflet + OpenStreetMap (real
Leaflet here — this runs in the browser, unlike the Flutter apps which use
flutter_map). For now this is a placeholder.
